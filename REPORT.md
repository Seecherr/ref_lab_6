## 1. Опис проєкту

VeloShop — це веб-додаток на базі Django для продажу звичайних та електровелосипедів. Додаток реалізує:

- Каталог велосипедів з фільтрацією за типом
- Систему реєстрації та авторизації користувачів
- Оформлення замовлень з автоматичним розрахунком ціни
- Адміністративну панель для управління каталогом та замовленнями
- Патерни проєктування: Builder (створення замовлень) та Facade (реєстрація)

## 3. Основні кроки реалізації

### 3.1 Dockerfile

Створено `Dockerfile` на основі `python:3.12-slim`:
- Встановлення системних залежностей (gcc, libpq-dev)
- Встановлення Python залежностей з `requirements.txt`
- Копіювання коду додатку
- Збірка статичних файлів (`collectstatic`)
- Запуск через Gunicorn на порту 8000

### 3.2 Docker Compose

Файл `docker-compose.yaml` визначає три сервіси:

| Сервіс | Образ              | Опис                                      |
|--------|--------------------|--------------------------------------------|
| db     | postgres:16-alpine | PostgreSQL з healthcheck та volume          |
| web    | ./Dockerfile       | Django + Gunicorn з автоміграцією           |
| test   | ./Dockerfile       | Запуск тестів (профіль `test`)             |

### 3.3 CI/CD Pipeline (GitHub Actions)

Конвеєр `.github/workflows/ci.yml` складається з трьох послідовних кроків:

1. **Lint** — flake8 перевіряє якість коду
2. **Test** — Django тести із SQLite
3. **Docker Build** — перевірка збірки Docker-образу

### 3.4 Тести

Написано комплексний набір тестів:
- Моделі: створення велосипеда, автоматична ціна замовлення
- Views: статус-коди, фільтрація каталогу, 404
- Аутентифікація: реєстрація, вхід, вихід
- Builder Pattern: regular/electric, скидання стану
- Facade Pattern: валідація, дублювання користувачів
